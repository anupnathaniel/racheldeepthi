# Image Review Checklist

Use this checklist for every Instagram-derived, award, event or community-health image before moving it into a published data record.

- [ ] Rachel approved the image
- [ ] Photographer or rights owner approved website use
- [ ] Event organizer approved use where needed
- [ ] Award organizer permits use of its name and visible branding
- [ ] Original high-resolution file received where possible
- [ ] No watermark or credit has been removed or cropped
- [ ] No confidential medical information is visible
- [ ] No prescription, report, form, badge, phone number or patient name is visible
- [ ] Patient or participant consent has been checked
- [ ] Other identifiable individuals have been considered
- [ ] Child safeguarding review completed where applicable
- [ ] Caption is factual and verified
- [ ] Alt text is specific, concise and complete
- [ ] Required photographer or organisation credit is displayed
- [ ] Certificate, presenter and event context remain visible where relevant
- [ ] Full-image viewing is available if a crop would remove essential context

A general website disclaimer is not a substitute for rights-owner or participant consent.
